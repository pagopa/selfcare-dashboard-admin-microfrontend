# AGENTS.md

Guidance for AI coding agents working in `selfcare-dashboard-admin-microfrontend` (React 18 + TypeScript + Vite + MUI v5, Module Federation remote). See also `.github/copilot-instructions.md` for architecture and conventions.

## Setup (required before type-check or tests)

```bash
yarn install
yarn generate   # creates src/api/generated/* and openApi/generated-* (gitignored)
```

Without `yarn generate`, `tsc` and many tests fail with missing-module errors. Requires Node >= 24 and yarn 1.

## Commands

| Task | Command |
|---|---|
| Dev server | `yarn start` |
| Type-check | `yarn typecheck` |
| Lint | `yarn lint` (`yarn lint-autofix` to fix) |
| Format | `yarn prettify` |
| Unit tests | `yarn test` |
| Single test file | `yarn vitest run src/path/to/file.test.tsx` |
| Coverage | `yarn test:coverage` (enforces thresholds) |

## Definition of done

1. `yarn typecheck` passes.
2. `yarn lint` passes with no new warnings.
3. Relevant tests pass (run targeted files, not the full suite, unless needed); add or update tests for changed behavior.
4. User-facing strings are added to `src/locale/it.ts` (the only locale in this repo).

## Do not edit

- `src/api/generated/**`, `openApi/generated-*` – regenerated by `yarn generate`. To change generated output, edit the specs in `openApi/*.json` or the fix scripts in `openApi/scripts/`.
- `.env*` secrets, `coverage/`, `build/`, `node_modules/`.

## Gotchas

- This app is a federated remote: `./RoutingAdmin` is the exposed module; changing its props/contract affects the host dashboard. Shared dependency versions are derived from `package.json`, `@pagopa/mui-italia` and `@pagopa/selfcare-common-frontend` in `vite.config.ts`.
- `vitest.config.ts` excludes `src/api/**`, `src/locale/**` and `src/services/__mocks__/**` from tests and coverage.
- Tests use real Italian translations via `src/i18n-test-setup.ts`.
- Routing uses React Router v5; do not use v6 APIs.
- Prettier: 100 cols, single quotes, semicolons, trailing commas `es5`.
